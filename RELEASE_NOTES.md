Version 2.0.2 keeps pending resolution and FPS selections when accessibility or VSync options change. A regression test exercises the actual menu and Apply-button callbacks. Installer shortcuts, launch and uninstall are verified before publication.

The Panda3D edition of Lead the Target brings a real 3D battlefield, a 100-encounter campaign, purchasable towers, fortress rebuilding and an evidence-based targeting and PIDF academy.

Choose **source.zip** if you want to edit the Python algorithms, **windows-portable.zip** to extract and play without installation, or **windows-setup.exe** for a per-user installation with shortcuts and an uninstaller. Windows downloads include Python and all game dependencies. Keep the entire portable folder together.

Resolution, display mode, FPS limits, VSync, compact bottom controls and accessibility options are available in Options. Display changes revert after 15 seconds unless confirmed.

This independent release is unsigned. It does not require administrator permissions. Online leaderboards are not included. See README and THIRD_PARTY_NOTICES for instructions, tested environments, limitations and licences.
